### Structure separates CLI implementation (commands/), config (config/), user content (content/), and browser-facing app code (scripts/, styles/, views/).

```
moracarta/
├── index.html                    # Main page / app entry point
├── package.json                  # Dependencies
├── vite.config.mjs               # Vite configuration
├── public/                       # Assets used by the application and repository
└── src/
    ├── commands/                 # CLI implementation, this is the only part that stays inside node_modules
    │   ├── add.js                # ´moracarta add´
    │   ├── deploy.js             # ´moracarta deploy´
    │   ├── postInstall.js        # Post-install hook
    │   ├── remove.js             # ´moracarta remove´
    │   └── setup.js              # ´moracarta setup´, also copies everything below into your own project
    ├── config/                   # Configuration files
    │   ├── cliConfig.js          # Main CLI config file
    │   ├── fonts.js              # Fonts configuration
    │   └── globalVariables.js    # Generated by setup.js, written straight into your project, not into node_modules
    ├── content/                  # Letter content files
    │   ├── letters.example.js    # Example letters / replaced by letters.js on ´moracarta add´
    │   └── letters.js            # User-generated letters
    ├── loaders/                  # Data loaders and utilities
    │   └── lettersLoader.js      # Checks whether we are loading example or user-generated letters
    ├── scripts/                  # Main JavaScript code
    │   ├── main.js               # Animation and setup of the main page
    │   ├── lettersPage.js        # Animation and setup of the letters page
    │   └── templateBinding.js    # Injects variables into HTML elements
    ├── services/                 # External service integration
    │   └── googleDocs.js         # API call to get text content from Google Docs
    ├── styles/                   # Stylesheets
    │   ├── main.css              # Animation and general style of the main page
    │   └── letters.css           # Animation and general style of the letters page
    └── views/
        └── letters.html          # Letters page HTML
```
